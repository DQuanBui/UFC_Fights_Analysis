# UFC Analytics: Evolution, Fighters & Fight Outcomes

An analysis of the local Kaggle MMA snapshot, with explicit UFC event scope,
auditable data preparation, historical fighter features, and interactive exploration.

Source: [UFC Datasets 1994–2026](https://www.kaggle.com/datasets/neelagiriaditya/ufc-datasets-1994-2025).
The source files are preserved byte-for-byte in `data/raw/`.

## Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```
